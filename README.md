# Aether 1.0 "Nebula"

Alpine Linux tabanlı, hafif ve Türkçe bir işletim sistemi. **Yapımcı: Hot Zot**

- Site: https://aether-os.dev
- İndir: [Releases](https://github.com/1260120047-eng/aether/releases/latest) sayfasından `aether-1.0-nebula.iso` (370 MB) ve Windows için `Eclipse-Windows.zip`

## Özellikler
- RAM'den canlı açılış ve kurulum sihirbazı
- Openbox masaüstü, açık ve koyu tema, Türkçe/İngilizce
- Eclipse web tarayıcı (WebKit, JavaScript destekli); Windows sürümü WebView2 ile
- gcc, g++, make hazır; SDL2/OpenGL geliştirme eklentisi

## Kurulum (VirtualBox)
Linux / Other Linux (64-bit), 2 GB bellek, 10 GB disk. ISO'yu CD sürücüsüne tak ve başlat.
Ekran siyah kalırsa önyükleme menüsünden "Güvenli grafik"i seç ya da 3D hızlandırmayı kapat.

I'm building my own operating system, out of curiosity.

Hi, I'm Hot Zot. Aether is a small Linux distribution I build on top of Arch Linux. Most of the programs inside it, from the window manager and file manager to the app store and web browser, I wrote myself in C.

Download Aether 2.0 ISO · 798 MB Source code (GitHub)

What I do

I wanted to see what goes on inside an operating system. Then it grew into something with its own installer, its own settings app and even its own web browser. It's all open source.

A

Aether Linux

A Linux distribution that runs from RAM at boot and installs to disk if you like it, even alongside Windows. Arch repositories and Flathub in one click.

C

Desktop apps

The Yörünge window manager, taskbar, file manager, app store, task manager, terminal and installer. All written in C with GTK 3 and Xlib.

E

Eclipse browser

My own WebKit-based web browser: tabs, bookmarks, private windows and an ad blocker. There's a Windows 10/11 version too.

What's inside

Aether's own apps on an Arch Linux base with a current Linux kernel. The interface is in Turkish and English (pick English in the boot menu).

App Store

The Arch repositories and Flathub in one place: Firefox, Discord, Steam, LibreOffice, OBS... in one click.

Aether Files

Copy progress, a trash can, drag and drop, "Open with".

Task Manager

Ctrl+Shift+Esc. Processes plus CPU, memory, disk and network graphs.

Game Mode

Steam and the graphics driver in one click, and a performance mode.

Yörünge desktop

Taskbar, desktop icons, Windows-style right-click menus, light and dark themes.

Installer

Language, keyboard, user, disk. It can also install alongside Windows.

Everyday things

Wi-Fi, sound, notifications, a Drivers page in Settings. A tabbed terminal, text editor, calculator, Minesweeper.

For developers

gcc, make and sudo pacman -S ready to go. 3D acceleration in virtual machines.

Installing

I've tested it in VirtualBox and QEMU, where it works fine.

  1. Create a new VirtualBox machine. Type: Linux, version: Arch Linux (64-bit).
  2. Give it at least 2 GB of RAM (3 GB is more comfortable) and a 10 GB disk.
  3. Optionally, in Settings → Display, set the graphics controller to VMSVGA, tick Enable 3D Acceleration and raise video memory to 128 MB.
  4. In Settings → Storage, attach the ISO to the CD drive and start the machine.
  5. In the boot menu, choose English. It logs into a live session with no password. Try it as long as you like, then click Install to Disk in the welcome window (or the install icon on the desktop).
  6. When the install finishes, remove the ISO, restart and log in with your own account.

Installing alongside Windows on a real computer: back up your important files first, turn off Fast Startup and BitLocker in Windows, and turn off Secure Boot in your BIOS/UEFI settings. Then choose to install alongside Windows in the installer and pick how much space Aether gets; at boot, a menu lets you choose between Aether and Windows.

Known issues

  • Not tested on real hardware; I could only try it in virtual machines. If you try it, I'd love to hear how it went.
  • Secure Boot isn't supported, so you need to turn it off.
  • If the screen stays black, choose Safe graphics in the boot menu, or turn off 3D acceleration in VirtualBox.
  • If VirtualBox shows a turtle icon at the bottom, Hyper-V is enabled on Windows and everything will be very slow.
  • 64-bit only.

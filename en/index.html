AETHER

download · install · known issues · comments · source code · türkçe

Hi, I'm Hot Zot. Aether is a small Linux distribution I made purely out of curiosity. I wanted to see what goes on inside an operating system; then it grew into something with its own installer, its own settings app and even its own web browser.

It's built on Alpine Linux and the ISO is around 370 MB. It loads into RAM at boot, and if you like it you can install it to disk. The interface is in Turkish and English (pick English in the boot menu).

What's inside

  • Linux 6.12 LTS kernel on an Alpine 3.22 base
  • Openbox desktop with light and dark themes (switch instantly in Settings)
  • An installer I wrote myself: language, keyboard, user, disk
  • Eclipse: my own WebKit-based browser, with tabs, bookmarks, history and private windows
  • Terminal, file manager, text editor, image viewer, calculator
  • Minesweeper, a starfield screensaver, a lock screen
  • gcc, g++ and make come preinstalled; SDL2/OpenGL development packages can be added from Settings
  • aether-info and aether-guncelle (update) in the terminal

The music player, system sounds and window animations are optional add-ons, so they don't bloat the ISO.

Installing

I've tested it in VirtualBox and QEMU, where it works fine. I haven't tried it on a real computer yet (see below).

  1. Create a new VirtualBox machine. Type: Linux, version: Other Linux (64-bit).
  2. Give it at least 2 GB of RAM and a 10 GB disk.
  3. In Settings → Storage, attach the ISO to the CD drive and start the machine.
  4. In the boot menu, choose English. It logs into a live session with no password. Try it as long as you like, then click Install to Disk in the welcome window (or Install Aether in the menu).
  5. When the install finishes, remove the ISO, restart and log in with your own account.

While the system is being copied into RAM at boot, the screen may sit still for about a minute. That's normal.

Known issues

  • Not tested on real hardware. Wi-Fi, sound and some graphics cards may not work. If you try it, I'd love to hear how it went.
  • If the screen stays black, choose Safe graphics in the boot menu, or turn off 3D acceleration in VirtualBox.
  • If VirtualBox shows a turtle icon at the bottom, Hyper-V is enabled on Windows and everything will be very slow.
  • 64-bit only.
